Import a license key

Personal seat · €40 / year · one named person · Ed25519 SNP1 token.

What you get

  • Full Generate and Neo 2 .samn playback for 365 days from issue
  • One key tied to one person (email / id)
  • Invite / internal keys exist for testers (no expiry)

While enforcement is off

Builds may still run fully without a key until go-live. Import still works so you can verify status early. When enforcement flips on, unlicensed Generate is capped at 1 minute; Funscript play stays available, Neo 2 .samn play needs a valid key.

Import steps

  1. Request a key — checkout is not automated yet: open a license request (€40 / year).
  2. Save the .key / token file you receive.
  3. In SamNPlayer open Settings → License.
  4. Import from file or paste the token, then confirm status shows licensed.
  5. Clear only if you intend to remove the seat from this machine.

Troubleshooting

  • Expired or wrong pubkey → status stays unlicensed; ask for a re-issue.
  • Do not publish your key; it is a personal seat.
