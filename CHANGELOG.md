# Changelog

Format loosely follows [Keep a Changelog](https://keepachangelog.com/).
Curated and grouped by theme, not a raw commit dump — see `git log` or
GitHub for the exact PR-by-PR history. `docs/NEXT.md` carries the detailed
measurement history behind each entry; this file is the short version for
"what changed", not "why" or "how it was measured".

## Unreleased

### Fixed

- **Player timeline:** the scene strip and the chapter bands are now as wide
  as the curve (they were 30 px narrower), so markers, bands and the curve
  share one time scale; the "+" sits inside the strip.
- **Create queue:** a file name containing `<` no longer breaks the list
  (names are always shown as text).

### Changed

- **Create layout (visual target `docs/visual-target/create.png`):** Create
  is now a three-column workspace instead of one long page. On the left is
  a Project column: source clips, recent videos, generated scripts, Scene
  map and the handbook. In the middle sit the project header, a step bar
  with sub-labels, the preview next to the source-clip card, and the step
  tools (Tip & contact, Create, Review) integrated under the stage so they
  stay in the centre column. On the right are the Feel settings with a large
  **Create Emotion Script** button and its progress. Every list shows real
  data; nothing is a placeholder control. Choosing a recent video in the
  Project column loads it.
- **Background (visual targets):** the background is now near-black navy
  with silky blue and orange light ribbons in the top-right and bottom-left
  corners, as in the mockups. The ribbons are SVGs generated by
  `scripts/art/flow_background.py`. The earlier faint lines are gone.

- **Editions renamed (Owner, 12 Oct):** **SamNPlayer Free** is the
  customer build; **SamNPlayer Suite** is our internal build with AI
  training and the batch test system (`-tags suite`, release files
  `SamNPlayer-suite-…`, formerly "studio"). The next major version is
  **SamNPlayer 2.0 Next**, also free, with no licence system. See
  `docs/EDITIONS.md`.
